# Design references

`references/` holds analyses of eight real design systems, taken unchanged from the
awesome-design-md collection (MIT licence in `LICENSE-awesome-design-md.txt`, source commit
in `SOURCE-commit.txt`). Each file covers colour roles, type, components, layout and the
system's guardrails.

| File | Situation | How it composes a screen |
|---|---|---|
| `wise.md` | sending money | a vivid lime green fills every primary action; near-black display type at weight 900; white cards on a pale tinted canvas |
| `revolut.md` | banking app | a stark black canvas, one brand violet and several fully saturated product colours |
| `coinbase.md` | trading | a pure white canvas, one blue kept for primary actions, quiet and confident |
| `airbnb.md` | booking | a white canvas, one coral on every primary action, photography, generous rounding |
| `spotify.md` | media app with dense lists | a near-black interface that lets the content supply colour, one green for actions, pill controls |
| `uber.md` | everyday service app | a black-and-white duet, a geometric display face, pill controls |
| `starbucks.md` | ordering and rewards | a warm canvas with deep green bands that own whole sections, one floating action button |
| `notion.md` | workspace tool | a deep navy hero band with illustrations, bold colour cards, a sober product canvas |

## How to use a reference

1. Pick the reference whose situation is closest to the product's (what people do there, how
   often, and on which devices), not the one whose colours you like.
2. Read how it composes a screen: how much of the screen its brand colour covers and where,
   the distance between its darkest and lightest areas, the size and weight of its display
   type, the second visual mass (cards, panels, bands, imagery), and how primary actions look.
3. Carry that composition into the product with the product's own palette, type and idea.
   Never copy a brand's colours, logo, name, wordmark, illustrations or signature shapes, and
   never name the brand in the product.
4. Say in the plan which reference you used and what you took from it.
